# 版本更新日志

> 版本号采用发布日期（YYYY.MM.DD）。

---

## 2026.09.07

### 新增功能

- **多导航 Tab**：顶部导航支持创建、重命名、拖拽排序、删除多个 Tab；每个 Tab 绑定一种内容形态（卡片/列表），分组归属 Tab，数据按用户隔离。
- **导航/分组两级管理**：新增「管理导航」弹窗，分组管理按当前 Tab 过滤并支持跨 Tab 移动；删除 Tab 可选「迁移分组」或「连带删除」。
- **站点品牌自定义（管理员）**：可配置站点名称与图标，联动浏览器标签、登录页与首页顶栏。
- **网络区域与内外网自动跳转（管理员）**：配置内网网段（CIDR / IP 前缀），服务端按访问来源 IP 判定内外网；书签填写「内网地址」后，在内网环境点击自动跳转内网地址。
- **卡片交互优化**：
  - 卡片不再展示完整网址，信息密度收敛为图标 + 名称（+描述备注）。
  - 卡片 hover 不再移动布局，仅边框/底色反馈，减少视觉干扰。
  - 操作收敛进右上角「⋯」菜单与鼠标右键菜单（编辑 / 置顶 / 复制链接 / 打开内网地址 / 删除）。
- **书签编辑增强**：所属导航→分组两级下拉；新增「内网地址」可选字段。
- **数据备份格式扩展**：导出包含导航 Tab 结构，并兼容导入旧版（无 Tab）备份自动重建。

### 修复

- 登录按钮加载文案由「正在抓取中」改为「登录中…」。
- 设置弹窗内容超高时可滚动，底部按钮不再被遮挡。
- 浏览器标签图标（favicon）在更换站点图标后不再因缓存而不刷新（图标地址带版本号，favicon.ico 移至 public 取消自动注入）。
- 右键卡片后菜单无响应 → 改为光标处弹出操作菜单。

### 其他

- 顶部导航区由两行合并为单行紧凑布局。
- 新增「多导航 Tab / 站点品牌化」产品需求文档（`doc/PRD-导航卡片交互与站点品牌化增强.md`）。
