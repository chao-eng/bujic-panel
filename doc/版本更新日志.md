# 版本更新日志

> 版本号采用发布日期（YYYY.MM.DD）。

---

## 2026.10.20

### 新增功能

- **MCP 接入（Agent 操作面板）**：新增 `/api/mcp` 端点（Streamable HTTP / JSON-RPC 2.0），AI Agent 可凭 Bearer 令牌调用 20 个 `panel_*` 工具，覆盖总览、导航空间、分组、书签、监控组件的查询与增删改；删除类工具需 `confirm` 二次确认。令牌在设置弹窗「MCP 接入」中创建与撤销，区分只读写权限，明文仅创建时展示一次，服务端只存 SHA-256 哈希。
- **设置弹窗改版**：Tab 由顶部横排改为左侧竖向导航，统一各页视觉风格与间距，内容超高时右侧独立滚动。
- **管理员可修改用户名**：修改自身用户名后清空令牌并要求重新登录。
- **登录后头部语言切换**：面板头部新增语言切换入口（纯图标，悬停提示目标语言）。
- **监控组件刷新间隔可配**：状态刷新支持自定义间隔并按配置分档轮询，页面隐藏时暂停。
- **品牌图标安全加载**：登录页与设置页品牌图标支持加载失败降级回退默认图标。
- **免责声明默认文案**：关于页免责声明为空时展示内置中英文默认文案。

### 修复

- 右键菜单被 `transform` 祖先节点影响导致定位偏移/被遮挡 → 菜单 portal 到 `body`。
- 图标代理返回缺失 `Content-Type` 时，按文件魔数嗅探识别真实图片类型。
- 内外网判定补充访问入口 Host 匹配，兼容 Docker 端口映射场景。
- HTTP 内网（非安全上下文）下「复制链接」按钮不生效 → 降级 `execCommand`，并改用 `copy` 事件劫持写入剪贴板。
- 监控组件卡片无右键操作菜单 → 支持右键弹出菜单。
- 设置弹窗英文下 Tab 标签过长出现横向滑块 → 改为自动换行。
- 上级目录存在 `pnpm-lock.yaml` 时 Turbopack 推断出错误工作区根，导致 `@prisma/client` 等依赖解析失败 → 固定工作区根目录。
- Beszel 监控系统信息字段映射错位，导致运行时长与温度取值错误。

### 其他

- **架构重构**：面板读写能力下沉为 `panelService`，favicon 抓取抽为独立模块，Server Action 与 MCP 工具复用同一服务层。
- **镜像发布改为手动触发**：GitHub Actions 工作流改为 `workflow_dispatch`，构建时录入版本号，仅推送「人工录入版本号」与 `latest` 两个标签，取消按日期的版本号。
- **代码质量**：清理全部存量 ESLint 问题（131 → 0），补齐 widget provider、监控组件与 UI/API 的显式类型，`tsc --noEmit` 与 `next build` 全量通过；弹窗内 props 同步改为渲染期状态调整。
- 「关于项目」页版本号徽标更新为 `v2026.10.20`。
- 新增 MCP 功能产品需求文档（`doc/PRD-MCP功能-Agent操作个人面板.md`）。

## 2026.09.07

### 新增功能

- **多导航 Tab**：顶部导航支持创建、重命名、拖拽排序、删除多个 Tab；每个 Tab 绑定一种内容形态（卡片/列表），分组归属 Tab，数据按用户隔离。
- **导航/分组两级管理**：新增「管理导航」弹窗，分组管理按当前 Tab 过滤并支持跨 Tab 移动；删除 Tab 可选「迁移分组」或「连带删除」。
- **站点品牌自定义（管理员）**：可配置站点名称与图标，联动浏览器标签、登录页与首页顶栏。
- **网络区域与内外网自动跳转（管理员）**：配置内网网段（CIDR / IP 前缀），服务端按访问来源 IP 判定内外网；书签填写「内网地址」后，在内网环境点击自动跳转内网地址。
- **卡片交互优化**：
  - 卡片不再展示完整网址，信息密度收敛为图标 + 名称（+描述备注）。
  - 卡片 hover 不再移动布局，仅边框/底色反馈，减少视觉干扰。
  - 操作收敛进右上角「⋯」菜单与鼠标右键菜单（编辑 / 置顶 / 复制链接 / 打开内网地址 / 删除）。
- **书签编辑增强**：所属导航→分组两级下拉；新增「内网地址」可选字段。
- **数据备份格式扩展**：导出包含导航 Tab 结构，并兼容导入旧版（无 Tab）备份自动重建。

### 修复

- 登录按钮加载文案由「正在抓取中」改为「登录中…」。
- 设置弹窗内容超高时可滚动，底部按钮不再被遮挡。
- 浏览器标签图标（favicon）在更换站点图标后不再因缓存而不刷新（图标地址带版本号，favicon.ico 移至 public 取消自动注入）。
- 右键卡片后菜单无响应 → 改为光标处弹出操作菜单。
- GitHub Actions 构建失败（`denied: unknown manifest class for application/vnd.oci.empty.v1+json`）：关闭 build-push-action 的 provenance/sbom 证明导出，阿里云 ACR 拒绝该类空清单导致推送失败。
- HTTPS 访问面板时内网 `http://` 图标被浏览器以 Mixed Content 拦截：新增同源图标代理 `/api/icon-proxy`，远程 http 图标经面板服务端转发加载。

### 其他

- 顶部导航区由两行合并为单行紧凑布局。
- 新增「多导航 Tab / 站点品牌化」产品需求文档（`doc/PRD-导航卡片交互与站点品牌化增强.md`）。
